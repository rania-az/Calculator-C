# Calculator-C
A simple calculator developed in C as a beginner programming project.

## Description
This project is a basic calculator that performs four arithmetic operations based on the user's selection.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division by zero error handling
- User input through the console

## Technologies
- C Programming Language
- Code::Blocks IDE

## Concepts Practiced
- Variables and data types
- `printf()` and `scanf()`
- Arithmetic operators
- Conditional statements (`if`, `else if`, `else`)

## How to Run
1. Open the project in Code::Blocks.
2. Build the project.
3. Run the program.
4. Select an arithmetic operation and enter two numbers.

## Project Level
Beginner
